# 💸 NexFi – Finance Dashboard

A clean and interactive **Finance Dashboard Web Application** built using **React.js and JavaScript** to help users track financial activity, analyze spending patterns, and manage transactions efficiently.

---

## 🚀 Features

### 📊 Dashboard Overview

* Summary cards for **Total Balance, Income, and Expenses**
* **Balance Trend (Time-based visualization)**
* **Spending Breakdown (Category-based chart)**

### 📋 Transactions

* View all transactions with:

  * Date
  * Amount
  * Category
  * Type (Income / Expense)
* 🔍 Search transactions
* 🎯 Filter by type
* 🔃 Sort by date or amount

### 👤 Role-Based UI

* **Viewer**

  * Read-only access
  * Can view dashboard and transactions
* **Admin**

  * Add new transactions
  * Edit existing transactions
  * Delete transactions

### 📈 Insights

* Highest spending category
* Monthly expense comparison
* Smart financial observations

### ⚙️ State Management

* Managed using **React State / Context API**
* Handles:

  * Transactions
  * Filters
  * User roles

### 🎨 UI/UX

* Clean and modern design
* Fully responsive (Mobile, Tablet, Desktop)
* Smooth interactions and hover effects
* Empty state handling

---

## ✨ Additional Features

* **Frontend:** React.js (JavaScript)
* **Styling:** CSS / Tailwind CSS
* **Charts:** Chart.js / Recharts

## 🧑‍💻 Getting Started

### 1. Clone the repository

```
git clone https://github.com/your-username/nexfi-dashboard.git
```

### 2. Navigate to project folder

```
cd nexfi-dashboard
```

### 3. Install dependencies

```
npm install
```

### 4. Run the app

```
npm start
```
